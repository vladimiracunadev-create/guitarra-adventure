# Guía para madres, padres y personas cuidadoras

## Propósito

La aplicación ayuda a organizar la práctica inicial, pero no evalúa por sí sola la postura completa, el tamaño correcto del instrumento ni una posible molestia física. El acompañamiento adulto debe centrarse en seguridad, constancia y ánimo, no en exigir perfección.

## Antes de comenzar

1. Confirma con una profesora o tienda especializada que el tamaño de la guitarra sea apropiado.
2. Revisa que las cuerdas, el puente, el mástil y la tapa no presenten daños visibles ni cuerdas a punto de romperse.
3. Prepara un espacio despejado, con buena iluminación y sin ruido excesivo.
4. Evita realizar ajustes grandes de clavijas sin experiencia.
5. Detén la actividad cuando exista dolor, adormecimiento, mareo o tensión persistente.

## Durante una práctica

- Prefiere sesiones breves y frecuentes.
- Pide que la niña describa cómo se siente el cuerpo antes de corregirla.
- Celebra un logro específico: un cambio de cuerda más limpio, mejor pulso o un sonido sin zumbido.
- Evita comparar con otras personas.
- Usa el afinador como referencia auditiva, no como única medida de éxito.
- Permite pausas; descansar también forma parte de aprender.

## Panel familiar

El panel permite:

- cambiar el nombre local y la meta semanal;
- activar texto grande o sonidos;
- exportar e importar respaldos;
- revisar prácticas, lectura musical e insignias;
- proteger cambios accidentales con un PIN de cuatro números.

El PIN es una barrera local sencilla. No protege frente a una persona con acceso técnico completo al dispositivo.

## Respaldo recomendado

Exporta el progreso después de cada semana importante o antes de cambiar de dispositivo. Guarda el archivo JSON en una ubicación administrada por una persona adulta. La aplicación no mantiene copias en un servidor.

## Actualizar la aplicación en Android

> ⚠️ **Por ahora, instalar una versión nueva obliga a desinstalar la anterior, y
> al desinstalar se borra el progreso.** Exporta el respaldo antes. Es una
> limitación temporal que se resolverá; mientras tanto, estos cinco pasos evitan
> cualquier pérdida.

1. **Antes de desinstalar nada**, abre la aplicación que ya tienes y ve al panel
   **Familia → Exportar respaldo**. Se descarga un archivo `.json`.
2. Comprueba que el archivo existe y ponlo en un sitio seguro (por ejemplo,
   envíatelo por correo o cópialo a otra carpeta). Si este paso falla, **no
   continúes**.
3. Desinstala la aplicación como cualquier otra, desde los ajustes del teléfono.
4. Instala el `.apk` nuevo. Android pedirá permitir «instalar aplicaciones
   desconocidas» la primera vez.
5. Abre la aplicación y ve a **Familia → Importar respaldo**. Selecciona el
   archivo del paso 1. Vuelven la racha, las insignias, las lecciones completadas
   y el historial de práctica.

Si al instalar aparece «aplicación no instalada», casi siempre es que la versión
anterior sigue ahí: desinstálala del todo y repite el paso 4.

En Windows no ocurre nada de esto: el instalador reemplaza la versión anterior y
conserva el progreso.

## Cuándo consultar

Solicita ayuda docente o técnica ante dolor, postura difícil de mantener, clavijas que se sueltan, cuerdas rotas, zumbidos que no desaparecen, dudas sobre el tamaño de la guitarra o la altura de las cuerdas, o dificultad persistente para producir un sonido estable.
