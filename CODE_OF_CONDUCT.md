# Código de conducta

Este proyecto debe ser un espacio respetuoso, educativo e inclusivo. No se toleran ataques personales, acoso, discriminación, sexualización de menores, exposición de datos infantiles ni contenido inapropiado para familias.

Las conversaciones técnicas deben centrarse en hechos, alternativas y mejora del producto. Los problemas de seguridad o privacidad deben comunicarse responsablemente según `SECURITY.md`.
